# ICS 604 Lecture Summaries (Split Index)

This folder contains one Markdown summary per lecture for ICS 604.
All lecture summaries in this folder are PDF-grounded and include:
- `Quick Overview` sections,
- topic-by-topic technical coverage,
- `In Layman's Terms` sections,
- `Language Bridge` sections when Python code or Python-specific concepts are discussed,
- per-file `Coverage Checklist (PDF + Notebook Verification)`,
- standardized `PDF source` / `Notebook source(s)` footers.

1. [Lecture 1: Intro + Course Logistics](01-intro-course-logistics.md) - Course logistics, DIKW framing, and the full tooling/scope roadmap for the class.
2. [Lecture 2: Pandas + Python Modules](02-pandas-python-modules.md) - Python module/package mechanics plus foundational Pandas objects, indexing, and CSV ingestion workflow.
3. [Lecture 3: EDA with Pandas](03-eda-with-pandas.md) - Core EDA workflow with schema inspection, descriptive statistics, missingness handling, sorting, chaining, and quick plots.
4. [Lecture 4: Arithmetic Ops + Data Alignment](04-arithmetic-ops-data-alignment.md) - Vectorized arithmetic, NumPy/Pandas alignment and broadcasting rules, and boolean-mask filtering patterns.
5. [Lecture 5: Data Preparation + Cleaning](05-data-preparation-cleaning.md) - Data cleaning pipeline design with dtype correction, string normalization, missing-data detection, and imputation strategies.
6. [Lecture 6: GroupBy + Split-Apply-Combine](06-groupby-split-apply-combine.md) - Split-apply-combine with `groupby`, including aggregation, transformation, filtering, thinning, and sampling patterns.
7. [Lecture 7: Hierarchical Indexing + Joins/Reshaping](07-hierarchical-indexing-joins-reshaping.md) - MultiIndex operations, reshaping via stack/unstack, and relational combining with merge/concat/combine-first.
8. [Lecture 8: Visualization with Matplotlib + Random Number Generation](08-visualization-with-matplotlib-random-number-generation.md) - Matplotlib figure/axes workflow, layout/styling patterns, and random number generation for simulation and plotting.
9. [Lecture 9: Introduction to Probability + Generative Process](09-introduction-to-probability-generative-process.md) - Probability foundations from sample spaces to simulation-based inference, including conditional reasoning with Monty Hall.
10. [Lecture 10: Probability Distributions + Binomial Distribution](10-probability-distributions-binomial-distribution.md) - Distribution modeling with random variables and Binomial PMFs, including parameter effects and probability-to-statistics transition.
11. [Lecture 11: Normal (Gaussian) Distribution + Kernel Density Estimation (KDE)](11-normal-gaussian-distribution-kde.md) - Continuous probability modeling with normal PDFs and nonparametric density estimation via KDE, including histogram limitations and kernel-based smoothing.
12. [Lecture 12: KDE Bandwidth + Parameter Estimation + Poisson Distribution + Bootstrap Confidence Interval](12-kde-bandwidth-parameter-estimation-poisson-bootstrap-confidence-interval.md) - Bandwidth selection tradeoffs in KDE plus parameter-estimation foundations, Poisson count modeling, and bootstrap confidence-interval interpretation.
13. [Lecture 13: Bootstrap Confidence Interval Review + Maximum Likelihood Parameter Estimation](13-bootstrap-confidence-interval-maximum-likelihood.md) - Bootstrap interval interpretation from repeated sampling and maximum-likelihood workflows for Poisson and Binomial parameter estimation.
14. [Lecture 14: Bayesian Parameter Estimation + Hypothesis Testing Intro](14-bayesian-parameter-estimation-hypothesis-testing-intro.md) - Approximate Bayesian parameter estimation with rejection sampling, posterior updating, and the core setup for hypothesis testing.
15. [Lecture 15: Hypothesis Testing, Comparing Means, and P-Values](15-hypothesis-testing-comparing-means-p-values.md) - Permutation-based null distributions for comparing means, p-value interpretation, and the general hypothesis-testing workflow.
16. [Lecture 16: Hypothesis Testing Examples, Comparing Means (Cont'd.), Proportions, and Multiple Categories](16-hypothesis-testing-examples-comparing-proportions-multiple-categories.md) - Worked hypothesis-testing examples covering the mean-comparison continuation, sample-vs-benchmark reasoning, proportion testing against a known baseline, and multi-category distribution comparison via total variation distance.
17. [Lecture 17: Hypothesis Testing: Common Tests](17-hypothesis-testing-common-tests.md) - Chi-squared goodness-of-fit and independence tests from the PDF, plus notebook extensions on one-sample z-tests, one-sample t-tests, and Welch's independent-samples t-test.
18. [Lecture 18: Standard Tests and Correlation](18-standard-tests-correlation.md) - Parametric mean-based hypothesis tests from the updated common-tests notebook, plus correlation intuition, covariance, Pearson's R, notebook extensions on R-squared and Spearman correlation, and correlation significance.
19. [Lecture 19: Correlation, Explained Variance, Spearman's Rank Correlation, and Linear Regression](19-correlation-linear-regression.md) - R-squared as explained variance, mean-versus-regression baselines, Spearman correlation and correlation significance, then simple linear regression, least squares, RSS, and bootstrap confidence intervals for regression coefficients.
20. [Lecture 20: Statsmodels, Multiple Linear Regression, and Non-Linear Regression](20-statsmodels-multiple-linear-regression-non-linear-regression.md) - OLS via `statsmodels`, multiple regression with holding-others-constant interpretation and confounding cautions, then nearest neighbor, step-function, and polynomial approaches to nonlinearity.
21. [Lecture 21: Polynomial Regression (Cont'd.), Time Series Analysis, and Pandas Time Series Tools](21-time-series-analysis-pandas-trend-seasonality.md) - Polynomial-regression overfitting and validation warning, introduction to time series structure and model classes, `pandas` datetime indexing tools, and exploratory detection of trend and yearly seasonality in the Mauna Loa CO2 example.
22. [Lecture 22: Time Series Trend Modeling, Seasonality, Harmonics, and Forecasting](22-time-series-trend-seasonality-harmonics-forecasting.md) - Time-series model building with shifting and numeric time encoding, sliding-window smoothing, power-law trend fitting, sine-based seasonality, higher harmonics, and a simple 36-month forecast.
23. [Lecture 23: Residual Autocorrelation and Exponential Smoothing](23-residual-autocorrelation-exponential-smoothing.md) - Residual autocorrelation as a model check, then smoothing-based forecasting from moving averages to single and double exponential smoothing.
24. [Lecture 24: Triple Exponential Smoothing, Clustering, Distance Measures, and Hierarchical Clustering Setup](24-triple-exponential-smoothing-clustering-distance.md) - Triple exponential smoothing with Holt-Winters, then clustering foundations through distance and similarity measures, Jaccard distance matrices, custom metric rules, and the first hierarchical clustering setup.
25. [Lecture 25: Hierarchical Clustering, K-Means, Silhouette Scores, and Mixture Models](25-hierarchical-kmeans-silhouette-mixture-models.md) - Hierarchical linkage choices, K-means assignment and inertia, silhouette-based cluster evaluation, and mixture models with EM and Gaussian Mixture Model notebook extensions.
26. [Lecture 26: Mixture Models, EM, Gaussian Mixture Models, and Clustering Example](26-mixture-models-em-gmm-clustering.md) - Mixture distributions, soft membership, EM updates, GMM priors and convergence cautions, component selection by likelihood, and a PDF-embedded clustering example using `KMeans` and `GaussianMixture`.
27. [Lecture 27: Machine Learning, Scikit-Learn, Iris Data, and Logistic Regression](27-machine-learning-scikit-learn-logistic-regression.md) - Machine learning definitions and task types, scikit-learn's shared fit/predict/transform interface, Iris dataset inspection, and the companion logistic-regression notebook extension.
